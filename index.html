Всё, что нужно — ничего лишнего

Продуманный до мелочей интерфейс, который не мешает работать и всегда под рукой.

Определение трека

Виджет сам находит запущенный Spotify и показывает название песни и исполнителя — без всяких настроек.

Точное состояние

Читает аудио-сессию Windows напрямую — статус Play/Pause всегда совпадает с реальностью, до миллисекунды.

Полное управление

Play, Pause, Next, Previous — прямо из виджета. Не нужно переключаться на Spotify, чтобы перелистнуть трек.

Живой эквалайзер

30 анимированных полос танцуют в такт музыке и плавно замирают на паузе. Мелочь, а приятно.

Ноль зависимостей

Только PyQt6. Никаких WinRT, winsdk, Spotify API и OAuth. Один файл — одна установка.

Собран в один .exe

Упаковка в один файл через PyInstaller — запускается двойным кликом, автозапуск в один ярлык.

Как это работает

Никакой магии и API. Всё прозрачно и локально — данные не покидают твой компьютер.

01

Находит окно Spotify

Виджет перебирает все открытые окна Windows и определяет нужное через имя процесса.

02

Читает заголовок

Из заголовка окна извлекаются название трека и исполнитель — без обращения к серверам.

03

Слушает аудио-сессию

Через Core Audio API проверяет активность аудиопотока — это и есть Play/Pause статус.

04

Отправляет команды

Play/Pause/Next/Prev передаются как настоящие медиа-клавиши — Spotify реагирует мгновенно.
